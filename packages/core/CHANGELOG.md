# @allem-dev/core

## 0.2.0

### Minor Changes

- Initial release of Allem Dev -- the floating dev panel for React.

  - Network tab: fetch/XHR interception with expandable request details
  - Renders tab: React Profiler integration with hot components heatmap
  - State tab: state change timeline with value diffs and route tracking
  - Perf tab: Web Vitals, live FPS graph, memory chart
  - Errors tab: error catching with parsed stack traces and vscode:// links
  - Console tab: console.log/info/warn/error/debug interception
  - Storage tab: localStorage/sessionStorage browser
  - Request mocking, custom plugin API, error boundary, profiler wrapper
  - Panel chrome: resizable, three positions, dark/light/auto themes, keyboard shortcut
  - Portal isolation, lazy-loaded tabs, throttled store subscriptions
  - SSR-safe, zero CSS dependencies, TypeScript strict mode
